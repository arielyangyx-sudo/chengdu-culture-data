# 成都文化大数据有限公司 · 官网演示版

纯静态站点（HTML / CSS / 原生 JS），无需构建、无需后端，直接打开 `index.html` 即可浏览。

## 页面

| 文件 | 页面 | 说明 |
|---|---|---|
| `index.html` | 首页 | 轮播、数据概览、发展定位、业务体系、核心产品、数据脉搏、新闻公告、公司速览 |
| `about.html` | 公司介绍 | 公司概况、里程碑、数据总览、联系我们 |
| `business.html` | 业务体系 | 三大业务体系：智慧文旅解决方案 / 数据治理与平台运营 / 文化大数据资源建设 |
| `cases.html` | 核心产品与案例 | 6 大核心产品矩阵 + 3 个落地案例 |
| `news.html` | 新闻公告 | 新闻动态与通知公告，分页、分类、站内筛选 |
| `search.html` | 站内检索 | 全站关键词检索 |
| `admin.html` | 内容管理 | 演示后台，账号 `admin` / 密码 `cddb2026` |

## 本地预览

```bash
python3 -m http.server 8766
# 打开 http://localhost:8766/index.html
```

## 说明

- 内容依据公司公开资料与《信息核对与补充需求清单》的回填信息整理；Logo、ICP 备案号、部分数据指标仍为占位内容，正式上线前需替换。
- 管理后台数据保存在浏览器 localStorage，仅本机生效，不影响其他访问者。
- 页面为响应式布局，适配桌面与移动端；已做 `prefers-reduced-motion` 动效降级。
